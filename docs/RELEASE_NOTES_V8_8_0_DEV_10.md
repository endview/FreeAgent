# v8.8.0-dev.10：空闲回收维护不再阻塞前台操作

dev.9 的标签归档 CI 暴露一个竞争：回收站启动/定时维护在没有到期会话、也没有待重试文件时，仍会短暂取得全局执行锁。此时批量整理可能跳过一项并误报“有未结束任务”。

本版先只读检查是否有清理工作；队列为空时直接返回，不取得执行与附件锁。有到期项或失败文件重试时仍使用原保护边界。没有新增表、Run 状态或调度器，AffectWeave 逻辑不变。

新增回归先在原实现稳定失败，修复后通过；既有附件故障测试改为经过自动维护入口验证，保证无到期会话时仍能重试文件删除。管理批次、恢复/到期竞争与相关 race 继续验证。

本版保留 dev.9 的会话菜单、空间整理、批量操作和 7 天回收站，使用方法见[管理指南](CONVERSATION_MANAGEMENT.md)。存储仍为 schema 2：已升级 dev.9 的数据无需再次迁移；schema 1 仍须显式备份迁移，回退至旧 schema 1 程序须恢复对应备份。

最终归档、发布与 Hytron 实际检查结果在[会话管理验收记录](VALIDATION_CONVERSATION_MANAGEMENT_2026-11-16.md)追加。dev.9 标签及原附件保留，便于核对来源。
