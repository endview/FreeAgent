# v9.0.0-dev.7：Telegram 入站确认与队列诊断

- 已确认路由无效、且未入队或运行的 Telegram 更新先写入拒绝记录，再确认平台游标。记录绑定原更新，不保存正文与请求人资料。不能确认的响应不推进游标。
- 临时入站和轮询错误按 1 到 30 秒退避，并遵守平台的更长等待。掉线重连、丢失回执和重启沿用原有去重，不自动重发结果未知的外发动作。
- 渠道设置的「接收与投递诊断」显示是否有更新正在等确认、已等待多久、连续重试次数和最近一次入站推进时间。Bot 在线并不等于入站正在推进。

不改变权限、会话设置或 AffectWeave，不新增队列或数据库表。Core 与连接器继续成对使用 wire v4。本版为预发行；正式版仍需真人论坛话题、双账号确认和工具验收。
