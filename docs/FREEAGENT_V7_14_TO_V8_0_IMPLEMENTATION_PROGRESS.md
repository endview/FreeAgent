## PG 实施中的实际进展（2026-11-06）

- Core 默认依赖图只保留通用渠道协议；平台客户端进入 `freeagent-channel` 进程。
  GUI/CLI/渠道共用 Core 的权限、上下文和执行；模型与渠道凭据独立校验和保存。
- Windows 原存储版本的产品/示例包全量和 93 个 JS 测试通过。Debian 渠道测试曾因验证
  账号 HOME 不可写失败，已为隔离验证指定可写 XDG 缓存；不能记为 Linux 全部通过。
- PG 15.19：Windows 官方运行时实际启动成功；Linux 在 Hytron 独立目录从官方源码编译
  成功，包含 pg_trgm。常驻 `freeagent`、NPM 与公网配置尚未修改。
- 新 schema `fa`；每 Core 独立数据库与受限运行角色。原确认字节保留 TEXT，JSONB 作为
  类型化查询投影；元数据键使用 C 排序，避免默认 locale 破坏前缀范围查询。
- 消息引用改为 `(conversation_id,id)`，id 是该会话的局部序号；Run/Attempt 另有局部 seq。
  短事务内分配，回滚不发布未提交的游标；不再依赖全局 rowid。
- 专用连接持有 advisory lock；代次与 PG 触发器拒绝失锁/旧代次写入，失锁停止新执行。
  普通池上限 4，SQL/池等待和事务有界；外部动作不放进 DB 事务。
- 备份实现改为导出快照、pg_dump 与同快照附件清单，不暂停普通任务派发；恢复使用新库。
  真实恢复、并发写入和异常验收仍在进行，尚不能宣称完整备份闭环通过。
- 真实 PG 上，固定内容、模型恢复、渠道往返/丢 ACK/重启的定向测试通过。
  首轮迁移回归发现并修正动态参数编号、布尔值、元数据排序等问题；其他失败继续调查。

尚未完成：PG 全量与竞态、运行时异常/双平台便携包、真实 Provider 在新 Store 上验收、
Hytron 备份校验与最终切换。用户已授权切换，需在前述验收后执行。
