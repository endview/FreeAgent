# v8.5.1-dev.1：表达边界与 Web 模型入口修正

日期：2026-11-08。配套可选扩展：AffectWeave 1.0.1-dev.1。本轮保留已有 v8.5 工作和人物数据，不增加数据库、调度服务、插件 UI 运行时或旧版兼容层。

## 实际改动

- 普通 Core 删除回复 mode/default、自然段算法、专用 CLI reply-mode、模型 segment 动作及 reply.suggest RPC。投递设置仅保留资源/间隔上限与明确授权规则。
- AffectWeave 拥有完整一条/自然分段的选项、默认值、算法和具体部分。GUI 仅在扩展安装、启用、被本轮选中时添加入口；停用后普通对话仍可工作。
- 复用 manifest 的 model_settings/settings_schema、现有能力选择和 Run/队列快照，传递有限的通用 extension_settings。Core 接收 turn.finished.reply_parts，只核对来源、版本、最多三段、64 KiB、非空 UTF-8 与逐字节无损拼接。首次冻结前撤销恢复原回答，已冻结组与回执不重写。
- 输入区显式标识模型与思考。未声明思考能力时有可进入设置的提示；支持的 DeepSeek 开关/等级与 GPT 类等级仍分别映射，本轮选择不改默认，切换模型清除旧覆盖，窄屏工具栏可以换行。
- 人物默认选择保留其他扩展设置；人物状态、关系、记忆、数据库结构与主动动机均不因本修正而自动改变。
