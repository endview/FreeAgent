# FreeAgent v8.7.0-dev.1 验收记录

日期：2026-11-08。配套 AffectWeave 1.6.0-dev.1。保留此前未提交的 v8.5/v8.6 精简成果；本版发布同时包含这些源码。自动分析、表达建议、固定跟进、主动生成和人格演进均默认关闭。

## 已实现

Core 只增加通用 context_analysis / scheduled_generation 能力、可信输入/反馈引用、扩展触发身份、现有 Attempt 的一次性额度、Owner 有界派发与取消，以及原有 outbox 的原子关联和 receipt 投影。人物、情绪、关系、话题选择和拆段规则均在 AffectWeave。普通 Core 不 import 人物或平台实现，无启用规则时不创建主动定时器。

输入分析：每输入最多一次、每 Run 最多两次；无工具/隐式 Memory/附件/其他扩展，不自动重试或替代。辅助 UNKNOWN 留在原 Attempt，已确认片段仍可用于普通回答。完整片段/经历冻结，延迟提案预览不修改原请求，不叠加衰减。

主动执行：唯一总开关默认关闭，明确目标/来源/规则授权，空 adopted_inputs 的 scheduled 身份。按目标汇总空闲、未回复、静默、滚动额度，用户新输入优先；跨归类会话不比较局部消息序号。关闭会取消在途评估；卸载清除生成授权，重装不自动恢复。生成结果与 outbox 在同一事务关联，迟到清理不能覆盖真实回执，UNKNOWN 不重发。恢复备份关闭生成并取消复制的未结束机会。

GUI/CLI/AI 使用同一持久确认。人物扩展提供审阅、参数、交互、证据、演进/冻结/回退、共享投递设置和只生成预览。前端草稿切页保留，未安装/停用不显示人物表达控件。

- **NOT_RUN：真人 TG 主动开场、真实客户端收到后多轮接续、真机手机与新一轮原生 WebView2 操作。** Windows Computer Use 两个入口均因内核资源路径缺失无法初始化；Edge 不能替代原生设备验收。当前任务没有新的真人测试发送授权，未向生产私聊发测试消息。

- **UNKNOWN：** 被中断的模型/平台派发保留真实未知状态和额度；此词不是未运行的同义词，也不通过重跑消除。
- 本地原生扩展是用户信任的程序，不是恶意插件沙箱；结构与来源检查不能证明全部自然语言事实。模型品质、延迟与额度依实际 Provider。
