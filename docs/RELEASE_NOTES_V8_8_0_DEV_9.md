# v8.8.0-dev.9：会话管理、空间整理与 7 天回收站

本版为已发布的开发预发行版。会话管理、空间整理与回收站已完成，两平台最终归档验证通过，Hytron 已升级至本版和存储 schema 2。程序源码及发行标签为 `515c1c5d9b2f4ca3dbb7f305991cdaf0d8580748`；后续发布记录更新不改变程序归档。

后续标签 CI 发现空闲回收维护与批量整理的竞争，可能误报“有未结束任务”而跳过一项。[dev.10 修复版](RELEASE_NOTES_V8_8_0_DEV_10.md)已发布并部署 Hytron，建议采用该版本；本页保留 dev.9 当时的发布与部署记录。

## 使用变化

- 会话行和顶部「⋯」提供改名、置顶、移动、多选和回收。右键、Shift+F10 使用同一菜单，改名冲突保留草稿。
- 空间内容页支持分类、标题/时间/入口筛选、跨页勾选、批量移动和清理。批量清单绑定确切 ID，后来新增的会话不被带入。
- 回收站保留 168 小时，可查看、恢复、永久删除所选或清空；Owner 启动及每小时执行有界到期清理。
- 删除空间默认同时回收其中会话；取消勾选则移到本地。运行任务、排队输入和在途消息先显示影响并处理。
- 托管附件可单独整理，物理删除失败可重试，分支独立副本保留。普通工作目录、Memory、Skill、扩展业务库由原入口管理。
- 必要 UNKNOWN 证据、去重与迟到回执保留，不因删除会话解除防重复执行。保留记录可从数据管理查看。
- Web、CLI 和 AI 提案共用控制记录。对话内移动/回收当前会话会先可靠结束本轮；新的会话永久删除只允许 Owner 显式操作。

## 升级要求

存储 schema 从 1 升到 2。旧库不会首次启动自动迁移；停止 Owner/渠道并核对任务后执行：

```text
freeagent store-upgrade --data-dir DATA --backup NEW_BACKUP --confirm
```

迁移先生成并验证完整备份。旧程序拒绝升级后的库；回退必须使用升级前程序与同一时点备份，不能只换二进制。

升级不自动回收任何既有会话，不改变 TG 明确未选中 AffectWeave 的状态，不升级或清空独立扩展。
