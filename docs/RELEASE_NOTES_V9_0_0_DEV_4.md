# v9.0.0-dev.4：群内设置确认与新会话默认能力

- Telegram 群或话题内，可提议修改当前会话已选、已启用扩展的一个现有选项。另一名已准入且在确认名单内的成员可以决定，发起人能撤回。设置提案不占用会话，普通工具审批仍只能由原请求人办理。
- 原卡、群与话题、成员、有效期和修订在提交时重新核实。Web 和 TG 共用原提案，决定只执行一次；批准仅影响后续 Run，不额外调用模型。群里不能切模型、启用扩展或更改全局设置。
- 工作台空间设置可以保存新会话默认选用的 Skill、MCP 和扩展。已有会话（包括明确不选）不回填，启用状态及权限继续独立校验。
- 补齐认证公网管理入口中的 Telegram 确认名单、群回复与背景及空间默认能力路由；未认证访问不开放。

Core 与渠道程序成对更新。没有改变 AffectWeave 的人物、主动发送或分段规则。本版本为预发行，真人群、话题及双人验收仍待完成。见[验收记录](VALIDATION_V9_W4_2026-11-22.md)。
