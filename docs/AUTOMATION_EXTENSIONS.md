# 浏览器与 Windows Computer Use 预览版

版本：Browser 0.1.1 / Computer Use 0.1.0，最低宿主 v8.9.0-dev.2。源代码和安装说明见[扩展 README](https://github.com/endview/FreeAgent/tree/main/extensions/automation)。下载对应平台扩展包并解压，在“设置 → 能力管理 → 扩展”导入其中的 `cc.endview.*` 文件夹。

## 归属与使用

浏览器属于 `cc.endview.browser`：独立 Chromium/Edge profile，标签、导航、DOM、截图、输入、滚动、下载、人工接管。Computer Use 属于 `cc.endview.computer-use`：Windows 本机窗口、UIA、截图、输入、按键和用户接管。安装和启用分别进行，输入区按本轮选择；不安装不启动任何浏览器/桌面进程。

Core 仅补通用调用范围、仅本机工具限制和附件产物校验，不引入浏览器/桌面 SDK、额外数据库或调度器。扩展通过真实 tools/list 向模型声明可用动作、目标引用和限制。

设置页直接编辑浏览器路径、无头模式、允许来源、允许程序，使用已有保存/回读、草稿及冲突机制。字段来自扩展 schema，不按扩展名在 Core 中分支。高级 JSON 仍可用。

## 浏览器

- 浏览器运行在 Owner 机器；公网网页不会获得访问者的本机浏览器。服务器用无头模式，本机需要接管时保存 `headless=false` 并重启扩展。
- 安装前提供 Chromium/Chrome/Edge；扩展不下载浏览器。当前包使用已安装的系统浏览器，验收记录写明版本，不宣称捆绑固定浏览器。
- 原生 profile 与用户日常浏览器隔离，并按 Core / 空间 / 会话分目录。停用保留登录态与下载；清除扩展数据才删除。
- 先打开、观察，再使用当次 tab/revision/ref。首版 DOM 元素操作仅主 frame；iframe 内交互暂不支持。DOM 重大变化、导航和操作后重新观察。
- HTTP(S) 子资源/重定向/WebSocket 经 DNS 与目的地址检查代理；默认仅公共 80/443 端口。精确来源白名单可显式授权独立测试站。禁用 QUIC、非代理 WebRTC、绕过 service worker 和扩展加载；不宣称这是恶意浏览器进程的完整 OS 沙箱。
- 下载按 GUID 跟踪，仅完成且不超过 8 MiB 的文件可以回传，最多 16 项；超限下载取消。截图/下载通过附件产物回传，不能让扩展指定任意宿主路径。旧图片只留引用，避免长期任务无限积累截图。
- 接管后自动操作暂停；无头且无图形入口时明确等待人工条件。密码/验证码不自动填写。不提供任意 JS、CDP 或本机文件协议。

## Computer Use

- 首版仅 Windows 已登录交互桌面；系统 .NET Framework 4.8 / UI Automation，无需额外 Python。默认允许程序为空。
- 配置精确的程序绝对路径；窗口身份绑定 HWND、PID 和进程启动时间。UIA 引用和截图坐标绑定当次观察、DPI、窗口边界、受众，不能跨窗口复用。
- 本机面板显示暂停/控制中，用户决定启用。Ctrl+Alt+Escape 紧急停止；输入或前景窗口变化会阻止下一项自动操作。激活失败不向其他窗口输入。
- TG 与公网请求不提供/不能派发仅本机工具。远程来源事实保存到原 Run，重启后不因入口信息丢失变成本机授权。
- 不操作终端、命令入口、密码框、UAC、锁屏或安全桌面。实际输入成功只代表派发；保存/发送仍需再观察证据，UNKNOWN 不重复点击。
- 真实 150% 缩放已验证；100%/125% 和负坐标的数学映射通过独立测试，真实多显示器及其缩放组合尚未验收。支持预览不等于所有 Windows 应用无条件可控。

## 停止与卸载

暂停保留当前状态；停止浏览器会关闭此扩展会话，不代表撤回已提交的外部动作。Windows 浏览器树绑定 Job，宿主退出关闭其子树；Linux 使用独立进程组、父进程退出信号及只负责管道关闭清理的轻量守护进程，依赖系统 `/bin/sh` 与 `/bin/kill`。扩展卸载保留既有 Core 历史，不读写 AffectWeave 状态。
