# v8.9.0-dev.3：公网搜索设置修复

日期：2026-11-17。schema 2 无迁移。

- 修复已登录公网“联网搜索”页只有“服务器没有返回有效响应”的问题：公网路由表补齐搜索设置读取、保存和固定查询测试，沿用登录、Cookie、CSRF 与控制面权限。
- 加载失败显示明确状态和 HTTP 错误，并可直接重新加载；失败时不显示空白配置供保存。非 JSON 的成功响应也不能当作有效数据。
- 网络工具关闭时提供“设置网络工具”入口；说明仅使用搜索可不填普通 HTTP 来源。空下拉框显示“未选择”“选择已保存的 Key”等提示。
- 用真实 HTTPS PublicServer 验证登录、创建 Key、连接保存、刷新回读、测试连接和加载失败重试；没有用本机接口转发替代公网路由。检查 1440/1024/768/390/320 五种宽度。

Browser 0.1.1、Computer Use 0.1.0 沿用各自独立扩展包。升级程序保留搜索设置、凭据、会话和 AffectWeave 选择，不自动配置搜索 Key 或启用扩展。
