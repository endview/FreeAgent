# FreeAgent v8.0.0-dev.1 验收记录

日期：2026-11-06（Asia/Shanghai）。这是开发候选，不宣称签名发行或全部外部平台认证。
本记录覆盖 v7.14 执行恢复、v7.15 渠道拆分/固定内容、v7.16 统一设置及 v8.0 PostgreSQL。
生产部署结果另记于私有运维记录；发行包不包含用户数据、凭据或生产配置。

## 实现范围

- 模型错误分类、有限退避/恢复、新 Attempt 与原 UNKNOWN 关联；不覆盖原始事实。
  不确定工具只允许有界只读核查，不自动重放副作用。
- 平台客户端移入可选 `freeagent-channel`。默认 Core 依赖图没有平台客户端，未启用
  渠道时不启动运输进程；Core 负责身份范围、去重、输入采用、上下文和执行。
- 模型与渠道凭据分区；固定内容复用版本化 Memory，派发时重新校验可见性和撤权。
- 全局设置按一级/二级分类；Provider 草稿在切页、失焦时保留，秘密草稿不写 localStorage。
  正常关闭显式释放客户端；运行、待确认、其他连接或后台命令仍保留 Owner。
- PostgreSQL 15.19 是唯一 Store。使用新 `Harness-pg-v1`，无 SQLite 驱动、双写、回退或
  历史导入。随包实例自动初始化；本机外部 PG 使用同一 Store，退出时不停止外部服务。
- 单 Core 独立数据库/受限角色；专用 advisory lock、持久代次与写入 fencing。消息和
  Attempt 使用作用域内顺序；保留原始确认字节，JSONB 只承担结构化投影。
- 有限连接池、等待/取消与事务超时；导出快照和 pg_dump 在线备份、同快照附件清单、
  新库恢复。附件 COMMIT 回执未知时保留正文和事务核对标记。
- 显式关键词检索使用 pg_trgm；没有自动 RAG、后台知识治理或经验总结子系统。

## 大历史性能

同一 Hytron Debian 12，隔离验证账号，2 vCPU / 3 GiB 限制，PG 15.19，
`fsync=on`、`synchronous_commit=on`。测量时其他隔离整套测试已结束；普通生产服务仍在线。
这是实际 TaskService 与 Echo 的合成负载，没有真实 Provider 等待，不是冷缓存基准。

| 数据量 | 样本 | p50 | p95 | 重开耗时 |
| --- | --- | --- | --- | --- |
| 初始小历史 | 80 | 49.086ms | 66.563ms | 62ms |
| 10 万 Run / 40 万消息 / 30 万 Attempt，约 1.8 GiB | 200 | 75.938ms | 99.738ms | 859ms |

Attempt 查询实际使用 `(run_id,seq)` 索引。复现工具见
`scripts/benchmark-postgres.go`，必须由 `scripts/test-postgres.py` 提供隔离服务。
该测量不证明多 Core 调度、共享知识库或分布式能力已实现。
