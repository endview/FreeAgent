# FreeAgent v7.7.0-dev.2 preview

Windows desktop and Linux CLI/Web share one lightweight Owner and Store. This
preview includes the retained conversation-space/channel work and two foreground
conversations, plus the v7.7 maintenance and release fixes.

- GUI/Web → CLI → GUI/Web continuation includes one-shot abandon and backup.
- Provider profiles start disabled. Use the Provider switch, `key enable`, or
  explicitly add with `key add --enable`. Saving/enabling never discovers models.
- Sandboxed Git metadata is always read-only. The `git_write` escape is disabled.
- SSH local and remote ports may differ. Use numeric loopback addresses; local
  authentication and event streams use headers rather than a shared-port cookie.
- Windows/Linux archives use pinned, deterministic builds, embedded production
  UI and complete source-input checksums. Artifacts remain unsigned previews.

Current data format is Harness-v7. No migration or legacy platform is included.
The planned v7.9 attachment format will use a separate directory; v7.8 server
data is a preview and is not automatically transferred into it.

Live Telegram/Lark/QQ acceptance and current real Provider acceptance remain
NOT_RUN without dedicated applications/accounts/credentials. Local protocol
fixtures do not certify real platform operation. Linux server/bwrap sandbox,
attachments and the optional public login are subsequent staged deliverables.
