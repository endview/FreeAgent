# FreeAgent v7.10.0-dev.1 preview

Windows 桌面、Linux Web/CLI、可选外部渠道和公网入口继续使用同一 Owner、
TaskService 与 Store。此预览完成 v7.7 收尾至 v7.10 的轻量迭代。

- 接续与发布：在线一次性 CLI 备份/结束任务，异端口 SSH 隧道，Provider
  默认关闭，完整源码清单与两次干净构建校验。正式构建拒绝 dirty 源码；
  归档参考时间与实际构建时间分开记录。
- 服务器：显式安装非 root systemd 服务，管理命令、在线备份、可核对的
  启停/异常恢复；原有 UNKNOWN 不重放。
- Linux 沙箱：可选 Bubblewrap，独立用户/进程/挂载/网络 namespace，
  `.git` 只读，进程树清理；不可用时拒绝，Full 仍为明确的 host 执行。
- 附件：有界 UTF-8 文本、PNG/JPEG 输入；None 可理解用户明确上传的内容。
  三种模型协议按声明的视觉能力派发；支持不可变 `file_export`、回复另存、
  GUI/CLI 接续与包含附件的备份校验/还原。
- 公网 Web：Linux 上可选 Caddy HTTPS → 受限 Unix socket；单管理员、
  Argon2id、Secure/HttpOnly 会话、独立 CSRF 与明确路由列表。
  失败锁定、自动黑名单、全局保护、IP 名单、登录 Cookie 检测和会话绑定
  可分别设置，GUI、CLI 和 AI 提案使用同一控制入口。
- 远程最高权限默认 Full，与空间和原发起人权限取低；新空间仍为 None。
  降低立即约束后续派发，提高需本机确认。注销撤销读取会话，已开始任务
  由 Owner 结算；不会因重新登录而重放。
- Windows 配置替换有界等待短暂读取；持续失败返回既有控制回执，
  CLI 审批与继续等待 Owner 结算，不把尚未执行的旧状态当成结果。

使用独立 `Harness-v8`、Store v10、backup-v4。不提供旧库或旧平台迁移。
包内不含用户数据、管理员口令或 Provider Key，仍为未签名的开发预览。

已发布：[v7.10.0-dev.1](https://github.com/endview/FreeAgent/releases/tag/v7.10.0-dev.1)，
源码固定为 `51c539fa3a806bddad79d3b3848357f3249555d1`。
Windows 与 Linux 包各经两次干净构建比对；6 个发行资产先在草稿状态回下载
校验，公开后再次下载，均与实际验收的本地文件一致。校验清单、源码输入清单、
验收摘要和服务长测 JSON 随包发布。

实际通过 Windows / Debian 完整普通和 native race、84 项 JS 测试、
WebView2 GUI/CLI 接续、真实 systemd / Bubblewrap、附件与临时 CA 下的
HTTPS / JSON / SSE。独立 v7.8 生命周期构建实测 28,800 秒、480 次采样，
无额外重启，内存范围 24,342,528–31,539,200 字节；消息预算已恢复为 40，
专用长测服务已停用且 cgroup 清空。它不代替最终 v7.10 二进制的八小时验证；
最终包另有对应源码的功能、归档、原生界面和 HTTPS 证据。

当前限制：Linux 沙箱网络和宿主可访问的沙箱服务端口 NOT_SUPPORTED；
Windows 不提供公网入口；QQ 任意文件上传 NOT_SUPPORTED。Full/host
具有服务 OS 用户的文件权限，不构成控制面的 OS 隔离。

真实视觉 Provider、真实 Telegram/Lark/QQ 文件账号及公网系统信任证书
验收未运行。协议夹具和临时 CA 的 HTTPS 测试分别记录，不代替真实平台或
公网可信证书结果。实际测试与发布证据见
[实施记录](../FREEAGENT_V7_7_TO_V7_10_IMPLEMENTATION_PROGRESS.md)。
