# FreeAgent v7.11.0-dev.1 preview

本次集中改善文件扫描效率、离线诊断和服务器安装体验。

- 命令前后观察和文件搜索减少重复路径校验；每次读取仍检查路径、链接、
  私有状态与实际文件句柄。没有跨扫描内容缓存，文件变化立即重新读取。
- 无匹配搜索减少字符串分配。相同暖缓存数据下，Windows 一万文件扫描
  实测耗时下降约 47–49%；Debian 约 16–23%。嵌套目录也有下降。
  这是扫描基准，不代表每个任务的总耗时；小目录没有稳定加速结论。
- `doctor --text` 给出独立检查、状态及下一步处理建议；默认 JSON 保留。
  配置或数据库出错不会遮住其他独立问题，Provider 关闭会明确提示。
  诊断不解密凭据、不发送 Provider 请求，也不自动启用功能或修改数据。
- Linux 安装器提供 `--check`，在创建账号和目录前校验完整包清单、
  校验和、依赖、路径、账号、端口及已安装文件。活跃服务提示先备份和停止。
- 安装拷贝后复核内容，程序链接和管理文件原子发布；Owner 就绪检查有界。
  停止服务后处于 TIME_WAIT 的连接不会被误报为正在监听的服务。

使用当前 Harness-v8 / Store v10 格式。Linux 沙箱仍不联网；Full/host
可以在服务账号和 systemd 限制内使用宿主网络，不自动获得 root 权限。
Provider 与公网入口保持显式开启。此版本是未签名的 amd64 开发预览。
