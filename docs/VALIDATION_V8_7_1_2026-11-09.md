# FreeAgent v8.7.1-dev.1：上下文压缩可靠性

本批次是[统一计划](FREEAGENT_CONTEXT_COMPACTION_RELIABILITY_PLAN_2026-11-08.md)的第一阶段，不等待新 Provider 适配。数据格式与数据库结构不变。

## 实现

- 空正文输出截断不按相同配置自动重发，同时覆盖主回答与压缩。
- 摘要成品字节与有效输出 token 分开；内容修复整次共享一次，限流恢复继续遵守原策略及 Retry-After。
- 摘要失败 Attempt 保留，由调用方裁决父 Run。合法原上下文可继续；硬预算、取消、配置/权限冲突、存储故障和 UNKNOWN 不降级放行。
- 同会话、同有效配置的空摘要失败跨轮和重启抑制，只提示一次；相关配置改变或手动压缩成功后恢复。
- GUI/CLI 可查看暂停原因、实际调用与耗时；渠道回传有限业务提示，工具副作用和确认语义不变。
- `model.set_profile` 的 `{id, auxiliary_reasoning}` 支持只调整辅助思考，无需 Key 引用，不覆盖其它模型属性，仍需确认。
