# v9.0.0-dev.3 — 群聊、话题与群背景

本开发版交付 W3，Core 与渠道程序需要成对更新，沿用 channelwire v4。

- TG 话题目标贯通入站、Run、队列、命令、审批、文字、贴纸与附件；普通超级群回复链不会被误建话题，General 发信省略 thread ID。授权仍按 Bot/群管理；话题隔离上下文，不是成员间的保密空间。
- 同一话题复用单活跃 Run 和 20 条有界队列。原发起人的补充仍作引导，其他已准入成员作独立请求，采用时保留本人权限和实际采纳顺序。队满记录原因，未采用输入不进入模型上下文。
- 群升级的双向迁移事实可重复接收，保留原空间与会话。未派发、无旧消息引用的输出可迁移；旧卡与无法核实的回复引用暂停，已派发/未知结果仍归原操作，不在两个目标重发。仍待批准且从未派发的旧动作在权限变化后结束，释放会话；UNKNOWN 不据此清除。
- 订阅 Bot 成员状态，被移除/禁发后停止投递；普通成员降权重新核查群发言权，不把失去管理员身份当成永久禁用。
- 「渠道 → Telegram 接入管理 → 群回复与背景」可按群设置全部回复、保存背景和清空背景。两项默认关闭。背景仅文本、24 小时、有界、按话题隔离；不作为正式历史或摘要源。临时参考正文不保存在模型 Attempt 中，已正式输出的答复仍是正常记录。
- 旧版背景默认不进入上下文，可能含旧背景的摘要按可见性规则失效；管理员可明确清理活动存储中的旧背景，不删除正式 Run/回执。关闭保存立即清除临时背景，备份依原保留期限到期。
- 会话/空间整理同时处理话题路由，替换一个话题会话不改动其他话题。群内不开放经验总结、群模型切换或全局设置确认。

隔离验证见 [W3 验收记录](VALIDATION_V9_W3_2026-11-22.md)。真人群/话题验收仍为 NOT_RUN，W4 群设置确认、空间能力默认和 W5 工作继续推进；本开发版不是 v9 正式版。
