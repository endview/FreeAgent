本机系统 Edge 在初次启动时立即退出、未提供控制端口，未标成验收通过；切换为真实可用的 Chrome 后完成流程。完整 Core 联测也发现最小环境没有 ProgramFiles，已改用 Windows Known Folder 定位浏览器，不依赖扩大继承环境。

最终跨平台构建补齐了 UTF-8 manifest 读取。Linux 服务环境下另将 HOME/XDG 目录放进扩展私有 profile，并用生命周期守护处理扩展突然结束后的浏览器子进程；这些修正均在独立验证环境复核。

桌面初测暴露了本机启用按钮的重复输入和窗口激活问题，已改为幂等启用，并使用窗口线程附着/焦点核对；失败时保持暂停，不把文本发到错误窗口。150% 的成功记录来自修正后的实现。

本地证据：忽略目录 `output/automation-live/` 的桌面 RPC、截图、保护检查；`output/playwright/automation-v89-current/` 的设置页面与保存回读；Hytron `/var/tmp/freeagent-automation-20261117/` 的独立浏览器日志。具体凭据与用户窗口内容不进入公开报告。

NOT_RUN：真实 100%/125% 桌面与多屏切换、原生 UAC/锁屏切换、真实手机、真人 TG、需要账号登录/验证码的页面。iframe 元素操作、完整远程交互画面、跨机器桌面控制不属于 0.1.0 已支持范围。

搜索版 v8.9.0-dev.1 已独立发布并部署到 Hytron；这些扩展不会自动在生产安装或启用。后续宿主升级不覆盖既有会话能力排除或 AffectWeave 状态。

Browser 0.1.1 专项：Windows 使用暂停创建 → 加入 Job → 恢复初始线程，修正 Edge 启动器过早退出造成的子进程逃出清理范围。本机 Edge 仍不能建立控制端口，启动失败清理验收后残留进程为零；Chrome 完整流程及强退测试通过。修正只在浏览器扩展，不修改宿主版本。
