# FreeAgent v7.11：执行效率与安装排障

基线：`221fdca4c1b66c3510d279b603282ff91b66b7af`。范围按用户选择限定为核心
执行效率、安装与排障体验。Linux 沙箱联网暂缓；Full/host 在服务 OS 用户与
systemd 限制范围内使用宿主网络，不自动增加管理员权限。

## 实现

- 命令前后文件观察、文件搜索移除重复的逐文件路径验证。目录仍在遍历前检查，
  每次文件读取仍通过原有路径、私有目录、链接和打开句柄检查；不跨扫描缓存内容。
- 无匹配搜索先检查文件字节，减少逐行字符串分配；文件数、字节数和匹配数上限保留。
- `doctor` 汇总独立配置、数据库、Key 元数据、模型选择和沙箱结果；新增 `--text`，
  显示下一步处理建议。失败仍输出完整 JSON；不复制解码错误中的用户内容，
  不解密或使用凭据发起 Provider 请求，不修改设置或初始化缺失数据。
- 安装器新增 `--check`：在创建账号/目录之前检查完整包清单、校验和、路径、
  依赖、账号、端口和已安装文件。活跃服务显示备份/停止指引，缺少可选 Bubblewrap
  不阻塞 Full/host 使用。程序链接原子替换，拷贝后再次校验，Owner 就绪等待有界。
- 安装器回归进入 Windows/Linux CI，复用当前数据格式和发行流程。
