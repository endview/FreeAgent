## 已实现

| 范围 | 实际实现 |
| --- | --- |
| 连续执行 | 删除普通任务总步数/累计秒数配置、CLI 参数及 GUI 额度入口；保留步数、活动计时、取消和单次调用超时。显式协作子预算独立保留 |
| 窗口管理 | 声明的 token 总窗口/来源、本地字节预算、输出与安全预留、文本/图片估算、分项占用、上次实际 usage；消息读取分页不再构成消息数停机条件 |
| 自动/手动压缩 | 完整装配后按 80% 默认阈值检查；复用本次扩展/附件准备结果；保留最新用户要求和完整工具组；大工具数据分块；摘要修整至多一次；确定的 Provider 上下文拒绝允许一次压缩重试 |
| 插话/队列 | 现有消息正文加有界 meta 关联；指定 Run 插话、20 条待采用上限、FIFO、请求去重、事务采用与取消、停止/失败/UNKNOWN 暂停、Owner 恢复、模型/权限/渠道准入复核 |
| 工具过程 | Attempt 派发时刻、已记录耗时、模型延迟与 usage 分开投影；NOT_RUN/执行中/失败/取消标志/截断/UNKNOWN 来自保存事实。快照活动与消息有界 |
| 消息分支 | 用户消息替换或已完成回复继续；独立前缀和来源关系；附件独立绑定；源未决阻断；原文件不回滚，旧工具不重放；模型提案走现有控制确认 |
| 入口 | GUI/Web、交互 CLI、TG 复用 TaskService。公网新增接口继续使用登录/CSRF 边界；控制命令不会变成排队模型文本 |

没有增加独立调度器、Job 表、版本控制平台、RAG 或旧平台兼容层。
新源码仍使用一个 Owner、Store、Run、Attempt 和现有记录。

## 未运行、UNKNOWN 与限制

- 普通 Go 测试进程没有真实凭据，真实 Provider 用例默认跳过；上述 DeepSeek
  新功能验收在独立进程中实际完成。其他真实 Provider/Responses/搜索矩阵本次
  没有重跑，不能据此新增兼容性宣称。
- 本版 TG 插话、排队与准入/身份边界已做模拟；没有新增真实多账号/群验收。
  Lark/QQ 不扩大真实平台验收范围。
- 长执行与部分宿主条件/成本测试采用显式开关或主机条件，默认跳过与未运行
  会在原日志中显示；单独实际执行的长任务不能被默认 SKIP 掩盖。
- UNKNOWN 场景测试验证的是“不重放、保留结果与暂停队列”；不是把未知结果
  当作成功。上述真实压缩验收没有报告 UNKNOWN。
- 输入 tokens 仍是带来源标记的本地保守估算，不是精确 tokenizer。未知模型
  窗口使用本地资源预算；真实 usage 只属于对应已完成调用。
- 排队绑定明确模型；Auto 需先选定 profile。配置或授权变化会阻止条目，
  用户核对后取消/重新提交，不能静默替换模型或提高权限。
- 普通任务不再有统一总步数/时长保护；仍应使用停止、明确任务范围和各操作
  自身的超时。用户承担真实模型调用费用，这些不伪装成任务级硬上限。

## 生产状态与升级边界

本次验收使用 Hytron 独立目录、端口和数据。生产 v7.12 的 Telegram、公网 Web
与其他应用未停止或替换；验证前后生产配置与凭据文件一致。
生产升级须单独做任务核查、备份、明确的配置编辑和切换。没有改写旧冻结 Run，
也没有自动续跑原先未完成的工具。当前格式副本验证不等于恢复旧平台兼容。
