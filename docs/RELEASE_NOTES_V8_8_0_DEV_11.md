# v8.8.0-dev.11：设置分组、空间管理与会话菜单

对话侧栏只保留“设置”，原来的管理空间内容、回收站、保留的执行记录不再独立占据侧栏。设置左侧统一分为四个可折叠分组：工作台设置、能力管理、连接与数据、空间管理。组标题不带前置图标，字号 18.2px，比 14px 的项目大 30%；22 个具体项目配统一线性图标。

空间管理提供三个页面：空间内容、回收站、保留的执行记录。空间内容分为“会话列表 / 空间设置”，保留现有分类、移动、批量清理、附件整理、空间名称与权限设置。会话和空间菜单仍可直达；旧管理链接进入新的设置布局，已选会话与目标空间继续传递。

左侧全部展开后选择底部项目保持原滚动位置，只让右侧内容回到顶部。搜索可查找折叠组中的项目，浏览器前进后退和窄屏“设置列表 → 详情 → 返回”均保持可用；设置草稿、冲突和确认规则沿用既有实现。

桌面会话行的「⋯」默认隐藏，悬停或键盘聚焦时显示，菜单打开后保持可见。触屏直接显示，目标至少 44×44px，隐藏不改变行尺寸。

本版仅修改前端导航与交互，Core、AffectWeave 业务逻辑和存储 schema 2 保持不变；dev.9/dev.10 不需再次迁移。schema 1 升级仍按[管理指南](CONVERSATION_MANAGEMENT.md)显式备份迁移。
