# v8.8.0-dev.11：会话菜单按需显示

桌面侧栏的每个会话不再常驻显示「⋯」。鼠标悬停会话行时显示，移开后隐藏；鼠标点选当前会话不会让按钮一直留在页面上。

键盘聚焦行内按钮时仍显示菜单入口，打开普通菜单或右键菜单后保持可见。触屏设备继续直接显示，点击区域至少 44×44px。隐藏时保留原来的尺寸，标题和行高不会跳动。

本版复用既有 Radix 菜单，只调整前端样式及浏览器验收的悬停操作；存储仍为 schema 2。dev.9/dev.10 无需再次迁移，schema 1 的升级仍按[管理指南](CONVERSATION_MANAGEMENT.md)显式备份迁移。

115 项前端逻辑测试、lint、生产构建通过。Edge 对独立 Core/PG 完成 24 项管理与悬停交互检查，覆盖六种窗口比例、深色和 CSS 200% 缩放。真实手机与人工 WebView2 缩放未重测。

最终归档、发布和 Hytron 实际结果见[验收记录](VALIDATION_MENU_HOVER_2026-11-16.md)。
