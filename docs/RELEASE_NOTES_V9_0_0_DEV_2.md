# v9.0.0-dev.2 — Telegram 私聊设置确认

本开发版交付 v9 W2，沿用 W1 的诊断和 wire v4。需配套更新 Core 与渠道程序。

- 「设置 → 渠道」可维护每 Bot 一份数字用户 ID 确认名单；默认空，保存有修订与幂等回执，版本冲突保留草稿，可明确放弃后回读。名单不会授予聊天准入或工具权限，普通渠道配置和模型不能更改名单。
- 名单内、已准入的原发起人可在私聊确认当前会话模型，或已选中且启用的扩展的一个现有选项。人物需已获当前空间授权；不隐式选中扩展、不创建人物，不开启主动外发。
- 原生按钮绑定 Bot、聊天、原卡、请求人、目标、名单修订和连接代次；名单撤销再加回、连接更新、过期不能复活旧卡。无权点击只向点击者反馈；普通工具审批保持原规则。
- 合法批准/拒绝由宿主保存结果并结束原 Run，额外模型调用为零，仅下一轮生效。另一笔修改已满足完整目标时不再写；其他修订冲突需要重新预览。
- 群内设置与全局管理请求给出安全管理提示，不生成阻塞群聊天的设置提案，不把完整管理预览投到群里。群内扩展选项确认在 W4 交付。
- 连接器策略与执行循环分开：Core 复核精确决定并保存事实，连接器核实身份与允许范围；状态协议结构与扩展共用，不新增数据库表或平台账户体系。

验证与限制见 [W2 验收记录](VALIDATION_V9_W2_2026-11-22.md)。安装后不会自动填入真实确认人员，也不会改变旧会话的模型、扩展选择、群准入或主动发送。
