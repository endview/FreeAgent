# A+B 工作台正式迁移

视觉与交互依据用户确认的 `output/ui-concepts-20261115/COMBINED_DESIGN.md` 第三次修订。2026-11-15 用户确认开工。迁移复用现有 React、Radix、Core 接口与权限流程，不引入运行时依赖。

## 交付范围

1. 蓝灰侧栏、白色阅读区、B 的连续阅读排版、深色主题与窄屏布局。
2. 对话作为主工作区；设置独立导航，分工作台、能力管理、连接与数据；保持全部既有入口、保存和草稿逻辑。
3. 右侧概览最多三条单行动作；等待确认、失败、UNKNOWN 优先，组内最近更新优先；完整链条独立滚动、分页、筛选、展开。
4. 内置工具、Skill、MCP、扩展四类能力完整可见；配置可用性、轮次选择与实际使用证据分开。
5. 输入框选择只用于后续任务；每条回答保留生成模型，概览读取所选轮次快照。自动路由、回退与多个尝试保留独立证据。
6. 真实 Core 的发送、流式、审批、队列/引导、附件、历史、上下文与模型切换回归；多比例、深浅色、键盘、浏览器和生产 CSP 检查。

## 实现边界

执行链条复用现有 Attempt 的只读投影与分页，不增加数据库表或另一套运行状态。历史模型型号来自已保存绑定和响应，不读取当前可变配置补写历史。新增消息记录生成来源；旧消息有 Run 配置时标注“本轮配置”，连该信息也缺失时显示未记录。

设计保持阅读为主：16px 正文、约 1.95 行高、4px 间距基准，侧栏默认 232px、概览 258px；已有手动布局偏好保留。状态颜色复用语义 token；概览不自动抢焦点，确认仍在消息流内。
