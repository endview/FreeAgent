# Embedded read-only control web

This directory contains the React and TypeScript read-only Control Overview.
The committed `dist` directory is the exact asset set embedded by the Go
package. The package exposes an exact asset resolver only; it does not register
HTTP routes, enable the control plane, create a listener, or change the default-
off composition boundary.

In an explicitly enabled same-origin Control server, the browser exchanges one
short-lived handoff, retains only the rotating resume credential in tab-scoped
`sessionStorage`, keeps CSRF material in memory, and reads the bounded Overview
with exact scope headers and strong ETag revalidation. The interface derives
choices only from server-authorized scopes and current Workspace references. It
contains no business mutation, event stream, worker, or durable client cache.

Runtime dependencies are limited to React, ReactDOM, and TanStack Query. Node.js
and npm are build dependencies only. `scripts/Test-ControlWeb.ps1` reconstructs
the project in a disjoint external directory with exact npm, type-checks and
tests it, builds it, and requires every generated byte to match committed
`dist`.
